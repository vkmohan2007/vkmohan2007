## About Me

IT professional with **15+ years of overall IT experience** and **5+ years of hands-on DevOps and DevSecOps engineering**. I automate software delivery end to end — building CI/CD pipelines with **GitHub Actions, Jenkins, GitLab CI and ArgoCD**, provisioning cloud infrastructure as code with **Terraform and Ansible**, and running containerized workloads on **Docker, Kubernetes, Amazon EKS and ECS/Fargate**.

Security is part of the pipeline, not a stage after it: I embed **SonarQube quality gates, Trivy image scanning and OWASP Dependency-Check** into build workflows so vulnerabilities surface before production. On the operations side, I drive observability with **Prometheus, Grafana and CloudWatch**, and lead production support, incident troubleshooting and root-cause analysis.

I have shipped and deployed applications built in **Java, Python, .NET / C#, Rust, Node.js, React and Angular** — a full-stack background that lets me bridge development and operations teams rather than sit between them.

Currently **Team Lead — DevOps & Cloud** at Ortler Solution.

## DevSecOps Pipeline I Build

```text
 CODE  ──▶  BUILD  ──▶  SECURE  ──▶  SHIP  ──▶  RUN
   │          │           │           │          │
   │          │           │           │          └─ Prometheus · Grafana · CloudWatch
   │          │           │           │             Loki · Jaeger · ELK/EFK · Alerting · RCA
   │          │           │           │
   │          │           │           └─ Docker image ▸ ECR / Docker Hub
   │          │           │              EKS · ECS · Fargate · Helm · ArgoCD
   │          │           │              Rolling updates · Automated rollback
   │          │           │
   │          │           └─ SonarQube quality gate · Trivy image scan
   │          │              OWASP Dependency-Check · Secrets management
   │          │              IAM least-privilege · Secure config baselines
   │          │
   │          └─ Maven · npm · Webpack
   │             GitHub Actions · Jenkins · GitLab CI
   │
   └─ Git branching · Pull requests · Code reviews
```

| Stage | What I enforce |
| :--- | :--- |
| **Source control** | Branching strategies, pull-request reviews, release governance |
| **Build** | Automated builds and artifact creation with GitHub Actions, Jenkins, GitLab CI |
| **Security (shift-left)** | SonarQube SAST with quality-gate enforcement, Trivy container scanning, OWASP Dependency-Check |
| **Infrastructure** | Terraform modules for VPC, IAM, ECS, ECR, S3 and networking; Ansible for drift-free configuration |
| **Deploy** | Docker → Amazon EKS / ECS / Fargate, Helm, rolling updates, automated rollback, GitOps with ArgoCD |
| **Operate** | Prometheus + Grafana dashboards, CloudWatch metrics and logs, alerting, incident RCA |
